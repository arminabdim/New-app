# New-app

## midi/

`midi/Cinematic-Atmospheres.mid` — یک فایل MIDI (۲۲:۴۹) شامل ۱۶ قطعه‌ی ساخته‌شده
در حس‌وحالِ پلی‌لیستِ «Cinematic Atmospheres» (Zimmer، Einaudi، Richter،
Mansell، Glass، Paterlini، Djawadi، Jablonsky).

هر قطعه یک ساخته‌ی بدیع در همان گام/تمپو/قوسِ پویای اثرِ الهام‌بخش است،
نه ترنسکرایپتِ نت‌به‌نتِ آن.

* فایل خروجی: [`midi/Cinematic-Atmospheres.mid`](midi/Cinematic-Atmospheres.mid)
* مولّد: [`midi/generate_playlist.py`](midi/generate_playlist.py) — `python3 midi/generate_playlist.py`
